## 👋 About me

I build responsive, accessible interfaces and wire them up to real APIs. Most of my work is **React** and **Next.js** with **TypeScript**, Tailwind CSS, React Query and React Hook Form with Zod. I care about clean component structure, state that lives in the URL, and interfaces that behave the same in Arabic (RTL) and English.

🏢 Front-end trainee at **Elevate**, working in a team on a Next.js product with Git, pull requests, code review and daily stand-ups.

📊 Before that, seven months at **Namasoft** building ERP reports with SQL and JasperReports.

🌱 Right now I am learning testing with React Testing Library and going deeper into accessibility.
